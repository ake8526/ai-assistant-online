# ชุดคำสั่งทดสอบผ่าน LINE (ครบทุกฟังก์ชัน)

ไล่ทดสอบตามลำดับหมวด 0 → 18 ได้เลย บางหมวดต้องทำต่อจากหมวดก่อนหน้า (เช่น หมวดไฟล์ ต้องค้นไฟล์ก่อนถึงจะสรุป/ผูกได้)

**กติกาการทดสอบ**
- ก่อนเริ่มหมวดใหม่ พิมพ์ `/ล้างความจำ` เพื่อล้าง context เก่า (กันการตีความต่อเนื่องผิดหมวด)
- ถ้าค้างอยู่ใน draft จอง ให้พิมพ์ `/ยกเลิก`
- ช่องผลลัพธ์: ✅ ผ่าน / ❌ ไม่ผ่าน + สิ่งที่เห็นจริง
